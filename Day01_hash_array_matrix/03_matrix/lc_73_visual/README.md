# LC73 矩阵置零：讲解

题目：矩阵里某个元素是 0，就把它所在的整行、整列都变成 0。要求原地修改，额外空间 O(1)。

代码在 [lc_73.cpp](../lc_73.cpp)。讲解和动画用同一个 4 行 5 列的例子：

```text
1 2 0 4 5          0 0 0 0 0
6 7 8 9 1    →     6 0 0 0 1
2 0 3 4 5          0 0 0 0 0
6 7 8 0 9          0 0 0 0 0
```

这个例子里有 3 个 0：两个在内部，一个在第一行；第一列没有 0。

## 1. 为什么不能边扫边改（动画第 2 章）

最直接的想法是扫到 0 就立刻清掉这一行、这一列。问题是新写上去的 0 和原来的 0 分不清：后面扫到它们，又会多清一行一列。上面的例子这样做，最后整个矩阵都成了 0，而正确答案里第 1 行的 6 和 1 应该保留。

所以要**先记下哪些行、哪些列要清零，再统一改**。

## 2. 从两个数组到第一行、第一列（第 3、4 章）

最容易想到的是开两个数组：`row[i]` 记第 i 行要不要清零，`col[j]` 记第 j 列要不要清零。这样多用 O(m + n) 的空间。

矩阵自己就有一行一列可以借用：把 `row[]` 搬到第一列，`col[]` 搬到第一行。

- `matrix[i][0] == 0` 表示第 i 行要清零。
- `matrix[0][j] == 0` 表示第 j 列要清零。

代价是：第一行、第一列自己原来有没有 0，会被标记盖掉。所以动手之前，先用两个 `bool` 记下来。

## 3. 四步（第 5–8 章）

```cpp
// 第一步：记下第一列、第一行原来有没有 0
for(int i = 0; i < m; i++)
    if(matrix[i][0] == 0) firstCol0 = true;
for(int j = 0; j < n; j++)
    if(matrix[0][j] == 0) firstRow0 = true;

// 第二步：扫描内部，遇到 0 就在列首、行首打标记
for(int i = 1; i < m; i++)
    for(int j = 1; j < n; j++)
        if(matrix[i][j] == 0)
            matrix[0][j] = matrix[i][0] = 0;

// 第三步：按标记清零内部
for(int i = 1; i < m; i++)
    for(int j = 1; j < n; j++)
        if(matrix[0][j] == 0 || matrix[i][0] == 0)
            matrix[i][j] = 0;

// 第四步：最后处理第一列、第一行
if(firstCol0)
    for(int i = 0; i < m; i++)
        matrix[i][0] = 0;
if(firstRow0)
    for(int j = 0; j < n; j++)
        matrix[0][j] = 0;
```

用例子走一遍：

| 步骤 | 做了什么 | 矩阵 |
| --- | --- | --- |
| 第一步 | 第一列是 1、6、2、6，没有 0：`firstCol0 = false`。第一行有 `matrix[0][2] = 0`：`firstRow0 = true` | 不变 |
| 第二步 | (2, 1) 是 0：`matrix[0][1]` 和 `matrix[2][0]` 改成 0。(3, 3) 是 0：`matrix[0][3]` 和 `matrix[3][0]` 改成 0 | 第一行变成 `1 0 0 0 5`，第一列变成 `1 6 0 0` |
| 第三步 | 列首是 0 的第 1、2、3 列，行首是 0 的第 2、3 行，内部全部改成 0。(1, 4) 的列首是 5、行首是 6，保留 | 内部只剩 (1, 4) 的 1 |
| 第四步 | `firstCol0` 是 false，第一列不动。`firstRow0` 是 true，第一行全部改成 0 | 得到答案 |

第二步里，第一行原来就有的那个 0（`matrix[0][2]`）自动成了第 2 列的标记，不用特殊处理。

## 4. 两个细节（第 9 章）

1. **为什么要两个 `bool`**：`matrix[0][0]` 同时是第一行和第一列的开头，一个格子记不下两件事。这个例子里 `firstRow0 = true`、`firstCol0 = false`，两个答案就不一样。
2. **为什么第一行、第一列最后才改**：它们是标记。如果先把第一行清零，所有列首都成了 0，第三步会把每一列都清掉，(1, 4) 的 1 就被误清了。

## 5. 复杂度

时间 O(m·n)：矩阵扫了三遍。额外空间 O(1)：只多了两个 `bool`。

这和 [LC41](../../02_array/lc_41_visual/README.md) 用正负号当标记是同一个想法：把题目给的数组自己当成标记本。
