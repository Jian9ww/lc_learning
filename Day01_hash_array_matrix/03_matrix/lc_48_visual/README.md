# LC48 旋转图像：矩阵原地旋转

题目：把 n × n 的矩阵顺时针旋转 90°，必须原地修改，不能另开一个矩阵。

代码在 [lc_48.cpp](../lc_48.cpp)：`rotate` 是顺时针 90°，`rotate180`、`rotate270` 是两道思考题的写法。讲解和动画全程用 3 × 3 的例子：

```text
原矩阵        顺时针 90°     180°          逆时针 90°
1 2 3         7 4 1          9 8 7         3 6 9
4 5 6         8 5 2          6 5 4         2 5 8
7 8 9         9 6 3          3 2 1         1 4 7
```

## 1. 每个数去了哪（动画第 2 章）

看上面的例子：第 0 行 `1 2 3` 变成了最后一列，第 1 行变成中间一列，第 2 行变成第 0 列。也就是**第 i 行去了第 n − 1 − i 列**，行里从左到右的顺序变成了列里从上到下。所以：

```text
顺时针 90°：(i, j) → (j, n − 1 − i)
```

例如 2 原来在 (0, 1)，转完在 (1, 2)。

直接按这个公式搬，每搬一个数都会盖住目标位置上的数，得想办法暂存。有两种原地做法：拆成两次翻转（第 2–4 节），或者四个一组轮换（第 7 节）。

## 2. 三种基本动作

| 动作 | 位置变化 | 代码 |
| --- | --- | --- |
| 转置：沿主对角线翻折 | (i, j) → (j, i) | 对 `j > i` 的每一对 `swap(matrix[i][j], matrix[j][i])` |
| 左右翻转：每一行倒过来 | (i, j) → (i, n − 1 − j) | 对每一行 `reverse(row.begin(), row.end())` |
| 上下翻转：行的顺序倒过来 | (i, j) → (n − 1 − i, j) | `reverse(matrix.begin(), matrix.end())` |

`reverse(matrix.begin(), matrix.end())` 把“行”当成元素，整行整行地换位置，所以是上下翻转（迭代器区间见 note C.1）。

## 3. 顺时针 90° = 转置 + 左右翻转（第 3、4 章）

```text
(i, j) --转置--> (j, i) --左右翻转--> (j, n − 1 − i)
```

两步连起来，正好是第 1 节的公式。

```cpp
void rotate(vector<vector<int>>& matrix) {
    int n = matrix.size();
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) { // 遍历对角线上方元素，做转置
            swap(matrix[i][j], matrix[j][i]);
        }
        reverse(matrix[i].begin(), matrix[i].end()); // 行翻转
    }
}
```

这份代码把两步写在了同一个循环里：每一轮先把第 i 行转置好，再把这一行翻转。逐步看：

| 轮次 | 动作 | 矩阵（按行） |
| --- | --- | --- |
| 开始 | | `1 2 3 / 4 5 6 / 7 8 9` |
| i = 0 | 交换 2 ↔ 4、3 ↔ 7 | `1 4 7 / 2 5 6 / 3 8 9` |
| i = 0 | 翻转第 0 行 | `7 4 1 / 2 5 6 / 3 8 9` |
| i = 1 | 交换 6 ↔ 8 | `7 4 1 / 2 5 8 / 3 6 9` |
| i = 1 | 翻转第 1 行 | `7 4 1 / 8 5 2 / 3 6 9` |
| i = 2 | 没有要交换的；翻转第 2 行 | `7 4 1 / 8 5 2 / 9 6 3` |

边转置边翻转没有问题：轮到第 i 行时，它左边 `j < i` 的部分在前面几轮已经换好；而后面的轮次只会动第 i 行下面的行，不会再碰已经翻转的行。

## 4. 为什么 j 从 i + 1 开始（第 5 章）

转置是把 (i, j) 和 (j, i) 这一对交换一次。如果 j 从 0 开始，i = 0 时交换了 (0, 1) 和 (1, 0)，到 i = 1、j = 0 时又把它们换了回来：每一对都换两次，矩阵原样不变。只走对角线上方（`j > i`），每一对正好换一次。对角线上 `i = j`，是自己和自己换，不用管。

## 5. 思考题一：顺时针 180°（第 6 章）

```text
(i, j) → (n − 1 − i, n − 1 − j)
```

行号、列号都倒过来，所以是**左右翻转 + 上下翻转**，不需要转置。

```cpp
void rotate180(vector<vector<int>>& matrix) {
    for (auto& row : matrix)
        reverse(row.begin(), row.end());        // 左右翻转
    reverse(matrix.begin(), matrix.end());      // 上下翻转
}
```

连续做两次顺时针 90° 也能得到 180°，但交换的次数多一倍。

## 6. 思考题二：顺时针 270°，即逆时针 90°（第 7 章）

```text
(i, j) → (n − 1 − j, i)
```

先转置到 (j, i)，再把行号倒过来：**转置 + 上下翻转**。

```cpp
void rotate270(vector<vector<int>>& matrix) {
    int n = matrix.size();
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            swap(matrix[i][j], matrix[j][i]);   // 转置
    reverse(matrix.begin(), matrix.end());      // 上下翻转
}
```

它和顺时针 90° 只差最后一步：顺时针是左右翻转，逆时针是上下翻转。

两步的顺序不能随便换：转置之后再左右翻转是顺时针 90°；如果先左右翻转、再转置，得到的是逆时针 90°。

## 7. 另一种写法：四个一组轮换（第 8 章）

直接按位置公式搬。一个数搬走后，目标位置上的数也得搬，这样连下去，四个位置正好转一圈：

```text
(i, j) → (j, n−1−i) → (n−1−i, n−1−j) → (n−1−j, i) → (i, j)
```

所以四个一组轮换：先把一个存进临时变量，其余三个依次挪过去，最后把临时变量放回去。

```cpp
void rotate(vector<vector<int>>& matrix) {
    int n = matrix.size();
    for (int i = 0; i < n / 2; i++) {
        for (int j = 0; j < (n + 1) / 2; j++) {
            int tmp = matrix[i][j];
            matrix[i][j] = matrix[n - 1 - j][i];
            matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j];
            matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i];
            matrix[j][n - 1 - i] = tmp;
        }
    }
}
```

i 只走前 n / 2 行，j 只走前 (n + 1) / 2 列，一共遍历矩阵的四分之一，每个位置负责它所在的那一组四个数。n 是奇数时，中心那个数不动。

每一行赋值都是“这个位置 = 转过来之后应该在这里的那个数”：`matrix[i][j]` 的新值来自 `(n−1−j, i)`，因为按公式，`(n−1−j, i)` 上的数转完正好落在 `(i, j)`。

## 8. 一张表（第 9 章）

| 旋转 | 位置变化 | 做法 |
| --- | --- | --- |
| 顺时针 90° | (i, j) → (j, n − 1 − i) | 转置 + 左右翻转 |
| 180° | (i, j) → (n − 1 − i, n − 1 − j) | 左右翻转 + 上下翻转 |
| 逆时针 90° | (i, j) → (n − 1 − j, i) | 转置 + 上下翻转 |

旋转 = 两次翻转。记不住时，拿 3 × 3 手推一遍：先看行是不是变成了列，决定要不要转置；再看是左右翻转还是上下翻转。

## 9. 易错点

- 转置的内层循环写成 `j = 0`：每一对换两次，等于没换。
- 转置和翻转的顺序写反：顺时针变成逆时针。
- `ranges::reverse(matrix[i])` 是 C++20 的写法，C++14 要写 `reverse(matrix[i].begin(), matrix[i].end())`（见 note A.3）。
- 这些做法只适用于 n × n 的方阵。行数和列数不相等时，旋转后的形状变了，没法原地做。
- 两种写法都是时间 O(n²)、额外空间 O(1)。转置加翻转更不容易写错；四个一组轮换容易把下标写乱。
