## 1. 两个问题（动画第 1 章）

螺旋是一段一段的直线。每一段只要回答两个问题：**往哪走**，**走几步**。解法2 用一张方向表回答第一个，用一对会交换的 `n`、`m` 回答第二个。

## 2. 往哪走：方向表（第 2 章）

```cpp
static constexpr int DIRS[4][2] = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}}; // 右下左上
```

每个方向是一对数：行号变多少，列号变多少。

| di | 方向 | 行 i 变化 | 列 j 变化 |
| --- | --- | --- | --- |
| 0 | 右 | 0 | +1 |
| 1 | 下 | +1 | 0 |
| 2 | 左 | 0 | −1 |
| 3 | 上 | −1 | 0 |

走一步，就是把这一对数加到 `i`、`j` 上：

```cpp
i += DIRS[di][0];
j += DIRS[di][1]; // 先走一步
```

走完一段换下一个方向：`di = (di + 1) % 4`。`(3 + 1) % 4 = 0`，所以走完“上”又回到“右”。和解法1 的四段 `if` 相比，四个方向共用同一段代码。

## 3. 从 (0, −1) 出发（第 3 章）

```cpp
int i = 0, j = -1; // 从 (0, -1) 开始
```

起点放在第一个格子左边、矩阵外面。这样每一步都是同一个动作：先走一步，再记录。第一步正好落在 `(0, 0)`，不用单独处理第一个格子。`(0, −1)` 这个位置只是出发点，代码从来不读 `matrix[0][-1]`。

## 4. 每段走几步（第 4 章）

| 段 | 方向 | 步数 | 来历 |
| --- | --- | --- | --- |
| 1 | 右 | 4 | n：走满第一行 |
| 2 | 下 | 2 | m − 1：第一行用掉了，竖着只剩 2 行 |
| 3 | 左 | 3 | n − 1：最右一列用掉了，横着只剩 3 列 |
| 4 | 上 | 1 | m − 2 |
| 5 | 右 | 2 | n − 2 |

规律：横竖交替，每一段的步数都是“另一个方向还剩多长”。横着是 4 → 3 → 2，竖着是 2 → 1。

## 5. m-- 和 swap 在做什么（第 5 章）

代码只用两个变量，含义在循环里是固定的：

- `n`：这一段要走的步数。
- `m`：另一个方向的长度。

每一段做三件事：

```cpp
for (int k = 0; k < n; k++) { /* 走 n 步 */ }
m--;         // 这一段占掉了一行（或一列），另一个方向少 1
swap(n, m);  // 拐弯：下一段走的是另一个方向，把它的长度换进 n
```

以第 1 段为例：向右走完 `n = 4` 步，第一行用掉了，竖着只剩 `m = 3 − 1 = 2`。交换后 `n = 2`，正好是下一段向下要走的步数；`m = 4` 是横向的长度，等轮到它之前还会再减 1，变成 3。

## 6. 完整走一遍（第 6 章）

开始时 `m = 3`，`n = 4`，`size = 12`，位置 `(0, −1)`。

| 段 | 方向 | 走 n 步 | 记录的数 | m-- | swap 之后 |
| --- | --- | --- | --- | --- | --- |
| 1 | 右 | 4 | 1 2 3 4 | 3 → 2 | n = 2，m = 4 |
| 2 | 下 | 2 | 8 12 | 4 → 3 | n = 3，m = 2 |
| 3 | 左 | 3 | 11 10 9 | 2 → 1 | n = 1，m = 3 |
| 4 | 上 | 1 | 5 | 3 → 2 | n = 2，m = 1 |
| 5 | 右 | 2 | 6 7 | 1 → 0 | n = 0，m = 2 |

第 5 段走完，`ans` 里有 12 个数，循环结束。

## 7. 什么时候停（第 7 章）

```cpp
int size = m * n;
for (int di = 0; ans.size() < size; di = (di + 1) % 4) {
```

`ans` 里的个数达到 `m × n` 就结束。五段的步数 4 + 2 + 3 + 1 + 2 正好是 12。`size` 必须在一开始算好：循环里 `m`、`n` 一直在变，最后是 `n = 0`、`m = 2`，不能再拿它们相乘。

## 8. 写代码时要注意的

- **C++14 要在类外补一行定义**：`constexpr int Solution::DIRS[4][2];`。类里的 `static constexpr` 数组只是声明，不补会链接报错 `undefined reference to Solution::DIRS`；C++17 起不用写。
- `ans.size() < size` 是无符号数和 `int` 比较，会有 `-Wsign-compare` 警告，这里无害（见 note D.2）。
- 两种解法都是时间 O(m·n)，除答案外额外空间 O(1)。解法1 用四个边界，直观；解法2 把方向和步数都变成了数据，代码更短。
