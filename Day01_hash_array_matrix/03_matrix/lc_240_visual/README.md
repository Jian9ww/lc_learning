# LC240 搜索二维矩阵 II：讲解

题目：矩阵的每一行从左到右升序，每一列从上到下升序。判断 target 在不在矩阵里。

```text
 2  5  8 12 19

10 13 14 17 24
18 21 23 26 30
```

`target = 5` 能找到，`target = 20` 找不到。

## 1. 从哪个角出发（动画第 2 章）

站在左上角：它是最小的数。target 比它大时，往右、往下都会变大，两条路都有可能，一个也排除不了。

站在右上角：往左变小，往下变大。一边小、一边大，比较一次就知道该往哪边走：target 比它小，只可能在左边；target 比它大，只可能在下面。

## 2. 一次比较，排除一行或一列（第 3 章）

设“剩余区域”的右上角是 x。它是这一行里最大的，也是这一列里最小的。

| 比较结果 | 说明 | 动作 |
| --- | --- | --- |
| `x > target` | 这一列在 x 下面的数都更大，整列都不可能是 target | 排除这一列，`j--` |
| `x < target` | 这一行在 x 左边的数都更小，整行都不可能是 target | 排除这一行，`i++` |
| `x == target` | | 找到，返回 true |

排除之后，新的 `(i, j)` 又是剩下那块区域的右上角，同样的比较可以继续做。

```cpp
bool searchMatrix(vector<vector<int>>& matrix, int target) {
    int m = matrix.size(), n = matrix[0].size();
    int i = 0, j = n - 1; // 从右上角开始
    while (i < m && j >= 0) { // 还有剩余元素
        if (matrix[i][j] == target) {
            return true; // 找到 target
        }
        if (matrix[i][j] < target) {
            i++; // 这一行剩余元素全部小于 target，排除
        } else {
            j--; // 这一列剩余元素全部大于 target，排除
        }
    }
    return false;
}
```

## 4. 找 20：找不到（第 5 章）

| 比较 | 位置 (i, j) | x | 结果 | 动作 |
| --- | --- | --- | --- | --- |
| 1 | (0, 4) | 15 | 15 < 20 | 排除第 0 行，i = 1 |
| 2 | (1, 4) | 19 | 19 < 20 | 排除第 1 行，i = 2 |
| 3 | (2, 4) | 22 | 22 > 20 | 排除第 4 列，j = 3 |
| 4 | (2, 3) | 16 | 16 < 20 | 排除第 2 行，i = 3 |
| 5 | (3, 3) | 17 | 17 < 20 | 排除第 3 行，i = 4 |
| 6 | (4, 3) | 26 | 26 > 20 | 排除第 3 列，j = 2 |
| 7 | (4, 2) | 23 | 23 > 20 | 排除第 2 列，j = 1 |
| 8 | (4, 1) | 21 | 21 > 20 | 排除第 1 列，j = 0 |
| 9 | (4, 0) | 18 | 18 < 20 | 排除第 4 行，i = 5 |

i 到了 5，不满足 `i < m`，循环结束，返回 false。

## 5. 为什么最多 m + n 步（第 6 章）

每比较一次，就少一行或者少一列。一共只有 m 行、n 列，所以最多比较 m + n 次。

| 做法 | 时间 | 5 × 5 时 |
| --- | --- | --- |
| 一格一格找 | O(m·n) | 25 次 |
| 每一行做二分 | O(m·log n) | 约 15 次 |
| 从右上角排除 | O(m + n) | 最多 10 次 |

只用了 i、j 两个变量，额外空间 O(1)。

## 6. 两个细节（第 7 章）

1. **循环条件 `i < m && j >= 0`**：剩余区域是第 i 行到最后一行、第 0 列到第 j 列。i 越过最后一行，或者 j 越过第 0 列，区域就空了，说明找不到。
2. **起点可以换成左下角**：道理一样，方向反过来：`x < target` 往右（`j++`），`x > target` 往上（`i--`）。左上角和右下角不行，因为往两个方向走是同增或同减，比较完仍然有两条路。
