## 章节

1. 题目：例子 `nums = [1, 2, −2, 2, 1, 2]`，`k = 3`，答案 6
2. 原来的写法：固定起点 i，逐格累加，21 格只有 6 格是答案
3. 重复在哪：第 i 行 = 第 0 行 − P[i−1]，得到 `sum(i..j) = P[j] − P[i−1]`
4. 画成折线：子数组和 = 两点高度差；站在 j 往左找「低 k」的点
5. 查表代替内层循环：逐步跑优化版代码，看 freq 怎么变化
6. 一次查表 = 暴力表格里的一整列
7. 两个细节：`freq[0] = 1`；先查询再记录（k = 0 的反例）
8. 代价：空间 O(1) → O(n)，n = 20000 时 2 亿次加法 → 2 万次查表
9. 一句话总结
