## 文件与运行

- 源码文件名建议使用英文，例如 `LC0001_two_sum.cpp`、`knn.cpp`；中文题名保留在注释和练习清单中，避免当前工具链生成乱码文件名。
- 每个本地运行文件包含自己的 `main()`，算法逻辑放在独立函数中。
- 如需保存样例，使用同名 `.in`、`.out`；仅本地练习时由我们明确输入输出约定。
- 保存并打开目标 `.cpp`，按 `Ctrl+Shift+B` 编译，按 `F5` 调试；普通运行执行任务 `C++14: Run active file`。
- 原站支持 C++ 时按题目要求提交；不支持时在本地用 C++14 运行并核对结果。
