## 1. 读题

### 1.1 题目原文

下面是照截图逐字转写的题目。

> **21、核心路由器管理域规划**
>
> 某省骨干网中部署了多台核心路由器设备。为了提升网络运维效率，需要将这些物理分散的路由器逻辑上划分为 N 个管理域，要求同一域内的设备在地理位置上尽量靠近以便于统一调度。现采用 Bi-K-means（二分K-means）算法进行聚类：初始时将所有设备视为一个整体（初始簇 C0），通过不断分裂当前最“适合”的域（簇），直到域（簇）的数量达到 N 。
>
> **【公式说明】**
>
> - SSE（误差平方和）：SSE(C) = Σ_{p∈C} ‖p − μ‖²，其中 μ 为簇 C 的质心（坐标均值）。
> - SSE下降量：SSE_Grad = SSE(C_parent) − (SSE(C_child1) + SSE(C_child2))
>
> **解答要求**
>
> 时间限制：C/C++ 1000ms，其他语言：2000ms。内存限制：C/C++ 512MB，其他语言：1024MB。
>
> **输入**
>
> 输入数据包含：
>
> 1. 第1行：期望划分的管理域数量 N，1<=N<=20。
> 2. 第2行：核心路由器总数 L，表明接下来的 L 行是相关路由器的二维位置坐标，1<=L<=100。
> 3. 第3到最后一行：每一行是一个路由器的二维位置坐标 (x, y)，其中 x 为经度，y 为纬度。输入坐标数据均为整数，0<=x<=1000，且不同路由器的x坐标值不同; 0<=y<=1000。
>
> **输出**
>
> 输出Bi-K-means算法的每一轮分裂后，簇列表中各个簇路由器数量的降序列表。初始簇 C0 的路由器数量作为第0次分裂后的结果。
>
> **样例1**
>
> 输入：
>
> ```text
> 2
> 3
> 1 1
> 2 2
> 6 6
> ```
>
> 输出：
>
> ```text
> 3
> 2 1
> ```
>
> 解释：该样例期望将3个坐标分别为 (1,1), (2,2), (6,6) 的路由器划分为 2 个管理域（簇）。输出的第一行：第0次分裂后的结果，即：初始簇 C0 的路由器数量 3。输出的第二行：第1次分裂后的结果，按结果中簇的路由器个数降序排序列表为 2, 1。
>
> **样例2**
>
> 输入：
>
> ```text
> 1
> 2
> 2 3
> 5 5
> ```
>
> 输出：
>
> ```text
> 2
> ```
>
> 解释：不需要分割簇，直接返回初始簇的路由器数 2
>
> **提示**
>
> 1. Bi-Kmeans算法的最大迭代次数为 N（即：分裂后得到的域（簇）的总数量）。
> 2. Bi-Kmeans算法的分裂选择策略（平局判断）：
>    - 优先选择 SSE 下降量（SSE_Gradient）最大 的簇进行划分。
>    - 平局处理规则：如果多个簇的 SSE 下降量相同，则优先选择 路由器设备总数量较多 的簇进行划分；如果元素数量也相同，则选择时间上最早生成的一个簇进行划分。
> 3. K-means初始质心设置约束：在执行每一次 K-means（K = 2）分裂操作时，必须选取当前待分裂簇内 x 坐标最小 和 x 坐标最大 的两个设备点作为初始质心。严禁随机初始化，以确保结果的可复现性。
> 4. K-means收敛条件：当满足以下任一条件时，停止 K-means 迭代：
>    - 两个新质心的最大偏移量小于 1e-6。
>    - 所有路由器设备的簇归属不再发生变化。

### 1.3 题目描述：要我干什么

| 原文 | 意思 |
| --- | --- |
| 某省骨干网中部署了多台核心路由器设备。 | 有一批设备，每台有自己的位置。把它们想成地图上的点。 |
| 需要将这些物理分散的路由器逻辑上划分为 N 个管理域 | 把这些点分成 N 组。N 由输入给出。 |
| 要求同一域内的设备在地理位置上尽量靠近 | 离得近的点分在同一组。 |
| 现采用 Bi-K-means（二分K-means）算法进行聚类 | “聚类”就是把点分组，一组点叫一个“簇”。题目里“域”和“簇”是一回事。 |
| 初始时将所有设备视为一个整体（初始簇 C0） | 一开始只有一个簇，所有点都在里面。 |
| 通过不断分裂当前最“适合”的域（簇） | 每次挑一个簇，把它分成两个。Bi、“二分”说的就是一分为二。 |
| 直到域（簇）的数量达到 N | 簇数到了 N 就停。 |

前两句合起来：**给一批点，按远近分成 N 组。**

第三句给了分法，但留下两个问题：

1. 每次挑哪个簇？题目只说挑最“适合”的。答案在提示 2。
2. 一个簇具体怎么分成两个？答案在提示 3、4。

### 1.4 输入：给我什么

对照样例 1 的输入：

```text
2        ← N = 2：最后要分成 2 个簇
3        ← L = 3：后面有 3 行，每行一个点
1 1      ← 点 A (1, 1)
2 2      ← 点 B (2, 2)
6 6      ← 点 C (6, 6)
```

为了方便，后面都按输入顺序把点叫作 A、B、C……

三个要记住的细节：

- **数据很小**：最多 20 个簇、100 个点。不用担心超时。
- **坐标是整数**：很多量可以用整数精确地算，这一点代码里用到了（5.3 节）。
- **各点的 x 坐标互不相同**：看起来不起眼，但提示 3 要选“x 最小的点”和“x 最大的点”，有了这一条，这两个点才是唯一的。

### 1.5 输出和两个样例：要我交什么

| 原文 | 意思 |
| --- | --- |
| 输出Bi-K-means算法的每一轮分裂后 | 每拆一次，输出一行。 |
| 簇列表中各个簇路由器数量的降序列表 | 一行的内容：每个簇里有几个点，从大到小。 |
| 初始簇 C0 的路由器数量作为第0次分裂后的结果 | 还没拆的时候也要先输出一行，就是总点数。 |

样例 1 的输出：

```text
3        ← 第 0 次：一个簇，3 个点
2 1      ← 第 1 次：拆成两个簇，一个 2 个点，一个 1 个点
```

输出的只是点数。不用输出坐标，也不用说哪个点在哪个簇。

样例 2 的 N 是 1：一开始就是 1 个簇，已经满足要求，一次也不拆，只输出第 0 次的 `2`。

提示 1 说“最大迭代次数为 N（即：分裂后得到的域（簇）的总数量）”，意思是最后一共 N 个簇。每拆一次多一个簇，从 1 个到 N 个要拆 N − 1 次，加上第 0 次，正常情况下一共输出 N 行。（N 比点数还多时拆不到 N 个，见 4.5 节。）

### 1.6 公式说明：先认符号

| 符号 | 意思 |
| --- | --- |
| C | 一个簇 |
| p | 簇里的一个点 |
| μ | 质心：簇里所有点的坐标平均值 |
| ‖p − μ‖² | 点 p 到质心的距离的平方 |
| Σ | 把簇里每个点的这个值加起来 |
| C_parent | 拆之前的簇（父簇） |
| C_child1、C_child2 | 拆出来的两个簇（子簇） |

- **SSE**（误差平方和）：每个点到质心的距离平方，全部加起来。它衡量一个簇有多分散，点离质心越远，SSE 越大。
- **SSE 下降量**：拆之前的 SSE，减去拆之后两个簇的 SSE 之和。

这里只要求认识符号，第 2 节用样例 1 动手算。

### 1.7 四条提示：具体怎么做

| 提示 | 回答的问题 | 内容 |
| --- | --- | --- |
| 1 | 什么时候结束 | 簇的总数达到 N 就停。 |
| 2 | 每次挑哪个簇 | 第一级：SSE 下降量最大的。第二级：下降量相同，选点数多的。第三级：点数也相同，选最早生成的。 |
| 3 | 怎么把一个簇分成两个 | 用 K-means，K = 2。两个初始质心必须是簇里 x 最小的点和 x 最大的点，不许随机。 |
| 4 | K-means 什么时候停 | 满足一条就停：两个新质心的最大偏移量小于 1e-6；所有点的簇归属不再变化。 |

提示 2 里藏着一层意思：要比下降量，就得先知道每个簇拆开后是什么样。所以每一轮要把每个簇都“试着拆一次”，再选一个真的拆开。

“最早生成”指的是这个簇是在哪一次分裂时被拆出来的，越早拆出来的越优先。

### 1.8 用自己的话说一遍

- **给我什么**：N；L 个点的整数坐标，x 互不相同。
- **要我交什么**：还没拆时输出一行总点数；之后每拆一次输出一行，写每个簇的点数，从大到小。
- **怎么做**：
  1. 一开始，所有点是一个簇。
  2. 每一轮，把每个簇都用 K-means（K = 2）试拆一次。
  3. 选 SSE 下降量最大的簇；相同选点数多的；再相同选最早生成的。
  4. 把它真的拆成两个，输出一行。
  5. 簇数到 N 就停。

读完题还没真正弄懂的词：质心、SSE、下降量怎么算（第 2 节），K-means 怎么做（第 3 节）。

## 2. 质心、SSE 和 SSE 下降量

用样例 1 的三个点：A (1, 1)、B (2, 2)、C (6, 6)。

### 2.1 质心

质心 = 簇里所有点的坐标平均值。x 和 y 分开算。

```text
μx = (1 + 2 + 6) / 3 = 3
μy = (1 + 2 + 6) / 3 = 3
质心 μ = (3, 3)
```

质心是这组点的“中心位置”。它一般不是其中某一个点，坐标也常常是小数。所以代码里点用整数（`Point`），质心用浮点数（`Center`）。

### 2.2 SSE

每个点到质心的距离平方 = 横向差的平方 + 纵向差的平方。

| 点 | 算式 | 距离平方 |
| --- | --- | --- |
| A (1, 1) | (1 − 3)² + (1 − 3)² = 4 + 4 | 8 |
| B (2, 2) | (2 − 3)² + (2 − 3)² = 1 + 1 | 2 |
| C (6, 6) | (6 − 3)² + (6 − 3)² = 9 + 9 | 18 |

SSE = 8 + 2 + 18 = **28**。

- 用的是距离的平方，不开根号。
- 只有一个点的簇，质心就是它自己，SSE 是 0。

### 2.3 SSE 下降量

把 {A, B, C} 拆成 {A, B} 和 {C}：

| 簇 | 质心 | SSE |
| --- | --- | --- |
| 拆之前 {A, B, C} | (3, 3) | 28 |
| 子簇 {A, B} | (1.5, 1.5) | 0.5 + 0.5 = 1 |
| 子簇 {C} | (6, 6) | 0 |

下降量 = 28 − (1 + 0) = **27**。

下降量越大，说明拆这个簇越“值”：拆完之后，整体变集中得越多。选哪个簇来拆，比的就是它。

<details>
<summary>补充：下降量的另一种算法（不在代码里，帮助理解）</summary>

可以证明：下降量 = n0 × n1 ÷ (n0 + n1) × 两个子簇质心之间的距离平方。n0、n1 是两个子簇的点数。

样例 1：2 × 1 ÷ 3 × [(6 − 1.5)² + (6 − 1.5)²] = 2/3 × 40.5 = 27，和上面一致。

从这个式子能看出：两个子簇离得越远，下降量越大。所以“两个点相距很远”的小簇，下降量可能比“四个点挤在一起”的大簇还大（用例 08）。

</details>

### 2.4 整个流程

```text
开始：所有点是一个簇，输出它的点数（第 0 轮）
簇数 < N 时重复：
    ① 试拆：每个簇都用 K-means 分成两半，算出各自的 SSE 下降量
    ② 选簇：挑下降量最大的那一个（平局规则见提示 2）
    ③ 真拆：把它换成两个子簇，输出一行
```

“试拆”只是算一算，不改动现在的簇。每做一轮，簇数加 1。

样例 1 走一遍：第 0 轮输出 `3`。试拆唯一的簇，分成 {A, B} 和 {C}，下降量 27。只有一个候选，拆它，输出 `2 1`。簇数 2 = N，结束。

“分成 {A, B} 和 {C}”这一步是 K-means 算出来的，下一节讲。

## 3. K-means（K = 2）：把一个簇拆成两个

对应代码里的函数 `splitCluster`。

### 3.1 步骤

1. **选初始质心**：簇里 x 最小的点作为 c0（0 号质心），x 最大的点作为 c1（1 号质心）。
2. **分配**：对每个点，算它到 c0、c1 的距离平方 d0、d1。`d0 <= d1` 归 0 号簇，否则归 1 号簇。一样远时归 0 号。
3. **更新**：每个质心移到自己那一组点的平均位置。
4. **要不要停**：归属和上一轮完全一样，或者两个质心里移动得更远的那个，移动量小于 1e-6，就停。否则回到第 2 步。

结果是两个子簇：最后归 0 号的点是 `child0`，归 1 号的点是 `child1`。

### 3.2 完整例子（用例 05，跑了 3 轮）

6 个点：A (0, 6)、B (2, 0)、C (4, 0)、D (9, 1)、E (10, 5)、F (11, 0)。

初始质心：x 最小的是 A，x 最大的是 F。c0 = (0, 6)，c1 = (11, 0)。

**第 1 轮**，用 c0 = (0, 6)、c1 = (11, 0) 分配：

| 点 | 到 c0 距离² | 到 c1 距离² | 归属 |
| --- | --- | --- | --- |
| A | 0 | 157 | 0 号 |
| B | 40 | 81 | 0 号 |
| C | 52 | 49 | 1 号 |
| D | 106 | 5 | 1 号 |
| E | 101 | 26 | 1 号 |
| F | 157 | 0 | 1 号 |

例：C 到 c0 是 (4 − 0)² + (0 − 6)² = 52，到 c1 是 (4 − 11)² + (0 − 0)² = 49。c1 稍近，C 归 1 号。

更新：0 号簇 {A, B} 的质心是 ((0 + 2)/2, (6 + 0)/2) = (1, 3)；1 号簇 {C, D, E, F} 的质心是 ((4 + 9 + 10 + 11)/4, (0 + 1 + 5 + 0)/4) = (8.5, 1.5)。c0 移动了 3.16，c1 移动了 2.92。归属和上一轮不同（上一轮还没分过），移动量也不小，继续。

**第 2 轮**，用 c0 = (1, 3)、c1 = (8.5, 1.5) 分配：

| 点 | 到 c0 距离² | 到 c1 距离² | 归属 |
| --- | --- | --- | --- |
| A | 10 | 92.5 | 0 号 |
| B | 10 | 44.5 | 0 号 |
| C | 18 | 22.5 | 0 号（变了） |
| D | 68 | 0.5 | 1 号 |
| E | 85 | 14.5 | 1 号 |
| F | 109 | 8.5 | 1 号 |

质心移动之后，C 变成离 c0 更近，改归 0 号。更新：c0 = (2, 2)，c1 = (10, 2)。移动量 1.41 和 1.58。继续。

**第 3 轮**，用 c0 = (2, 2)、c1 = (10, 2) 分配：

| 点 | 到 c0 距离² | 到 c1 距离² | 归属 |
| --- | --- | --- | --- |
| A | 20 | 116 | 0 号 |
| B | 4 | 68 | 0 号 |
| C | 8 | 40 | 0 号 |
| D | 50 | 2 | 1 号 |
| E | 73 | 9 | 1 号 |
| F | 85 | 5 | 1 号 |

归属和上一轮完全一样，停。结果：child0 = {A, B, C}，child1 = {D, E, F}。

这次拆分的 SSE：父簇 144，子簇 32 和 16，下降量 96。

### 3.3 两个停止条件各在什么时候起作用

代码是 `if (same || maxMove < 1e-6L) { break; }`，满足一个就停。

| 轮 | 归属（A–F） | 和上一轮比 | 最大移动量 | 停不停 |
| --- | --- | --- | --- | --- |
| 1 | 0 0 1 1 1 1 | 第一次分（上一轮记作全是 −1） | 3.16 | 继续 |
| 2 | 0 0 0 1 1 1 | C 变了 | 1.58 | 继续 |
| 3 | 0 0 0 1 1 1 | 完全一样 | 0 | 停 |

- 归属没变时，质心是用同一批点算出来的，一定也没动。所以**平时都是靠“归属没变”停下来**。
- **只有 2 个点的簇靠第二个条件停**（用例 03）：初始质心就是这两个点自己，第一轮分配后每个簇只有一个点，新质心还是它自己，移动量是 0。但这是第一轮，上一轮的归属记作全是 −1，`same` 是 false。于是靠 `maxMove < 1e-6` 停，只跑 1 轮。

### 3.4 距离相等归 0 号（用例 04）

三个点 A (0, 2)、B (4, 0)、C (8, 2)。c0 = A，c1 = C。B 到 c0 是 4² + 2² = 20，到 c1 也是 4² + 2² = 20。

代码写的是 `if (d0 <= d1)`，相等时条件成立，B 归 0 号。这是这份代码的约定，题目没有明说。写成 `<`，B 就会归 1 号。

### 3.5 初始质心只是起点（用例 06）

6 个点：A (6, 0)、B (7, 0)、C (8, 6)、D (9, 6)、E (10, 6)、F (11, 0)。c0 = A，c1 = F。

| 轮 | 归属（A–F） | 变化 |
| --- | --- | --- |
| 1 | 0 0 0 1 1 1 | 第一次分 |
| 2 | 0 0 1 1 1 1 | C：0 → 1 |
| 3 | 0 0 1 1 1 0 | F：1 → 0 |
| 4 | 0 0 1 1 1 0 | 没变，停 |

F 是 c1 的起点，最后却归了 0 号簇。初始质心只决定从哪里出发，最后的两个簇是一轮一轮算出来的。

### 3.6 为什么不会出现空簇

代码里有一句 `if (cnt0 == 0 || cnt1 == 0) { return result; }`，防止某个簇一个点都没有（那样求平均会除以 0）。实际上它走不到：

- 第一轮：x 最小的点到 c0 的距离是 0，一定归 0 号；x 最大的点到 c1 的距离是 0，到 c0 的距离大于 0，一定归 1 号。两个簇都至少有一个点。
- 之后每一轮：每个质心是自己那组点的平均位置，在这组点“中间”。这组点不可能全都离对面的质心更近。

## 4. Bi-K-means 全流程

对应代码里的 `main`。

### 4.1 簇列表和每一轮的三件事

程序里有一个簇列表 `clusters`。每个簇记两样东西：它的点，和它的 `birth`（第几个生成的）。初始簇的 birth 是 0。

每一轮：

1. **试拆**：按列表顺序看每个簇。只有 1 个点的跳过；其余的用 K-means 试拆，得到下降量。
2. **选簇**：边试拆边记“目前最好的”。规则是下降量大的赢；下降量相同，点数多的赢；点数也相同，不替换（留下的是更早生成的）。
3. **真拆**：从列表里删掉选中的簇，在末尾加上它的 0 号子簇和 1 号子簇，然后输出一行。

### 4.2 完整例子（用例 07：3.2 节的 6 个点，N = 6）

第 0 轮输出 `6`。

| 轮 | 簇列表（括号里是 birth） | 每个簇试拆的结果 | 选中 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | ABCDEF(0) | ABCDEF → ABC + DEF，SSE 144 → 32 + 16，下降量 96 | ABCDEF | `3 3` |
| 2 | ABC(1) DEF(2) | ABC → A + BC，32 → 0 + 2，下降量 30（第一个候选）；DEF → DE + F，16 → 8.5 + 0，下降量 7.5（更小，不换） | ABC | `3 2 1` |
| 3 | DEF(2) A(3) BC(4) | DEF：7.5（第一个候选）；A：跳过；BC → B + C，2 → 0 + 0，下降量 2（更小，不换） | DEF | `2 2 1 1` |
| 4 | A(3) BC(4) DE(5) F(6) | A：跳过；BC：2（第一个候选）；DE → D + E，8.5 → 0 + 0，下降量 8.5（更大，换成它）；F：跳过 | DE | `2 1 1 1 1` |
| 5 | A(3) BC(4) F(6) D(7) E(8) | 只有 BC 能拆，下降量 2 | BC | `1 1 1 1 1 1` |

簇数到 6 = N，结束。一共输出 6 行。

两点说明：

- 第 3 轮的 DEF 在第 2 轮已经试拆过，程序还是重新算了一次。数据很小，这样重复计算没有问题。
- 第 3 轮输出时，三个簇的点数按列表顺序是 3、1、2，排序后输出 `3 2 1`。

### 4.3 簇列表怎么变

以第 2 轮为例，选中的是列表里的第 0 个（`bestIndex = 0`）：

| 操作 | 列表 |
| --- | --- |
| 拆之前 | ABC(1) DEF(2) |
| `erase`：删掉第 0 个，后面的往前挪 | DEF(2) |
| `push_back`：加入 0 号子簇，birth = 3 | DEF(2) A(3) |
| `push_back`：加入 1 号子簇，birth = 4 | DEF(2) A(3) BC(4) |

新簇总是加在末尾，birth 一直在增大。所以**列表里的簇一直按 birth 从小到大排列**。这一点决定了平局时怎么选（4.4 节）。

### 4.4 选簇的三级规则

| 规则 | 用例 | 第 2 轮的两个簇 | 选中 | 输出 |
| --- | --- | --- | --- | --- |
| 下降量大的赢，不看点数 | 08 | ABCD：5 → 0.5 + 0.5，下降量 4；EF：18 → 0 + 0，下降量 18 | EF | `6` / `4 2` / `4 1 1` |
| 下降量相同，点数多的赢 | 09 | AB：下降量 4；CDEF：下降量 4，点更多，换成它 | CDEF | `6` / `4 2` / `2 2 2` |
| 同上，点多的在前面 | 10 | ABCD：下降量 4；EF：下降量 4，点更少，不换 | ABCD | `6` / `4 2` / `2 2 2` |
| 下降量、点数都相同，更早生成的赢 | 11 | AB(1)：下降量 0.5；CD(2)：下降量 0.5，点数相同，不换 | AB | `4` / `2 2` / `2 1 1` |

- 用例 08：左边 4 个点挤在一起，右边 2 个点离得远。先拆的是点少的那个。如果误以为“先拆点多的”，输出会是 `2 2 2`。
- 用例 09：如果平局时没有按点数选，拆了 AB，输出会是 `4 1 1`。
- 用例 11：这个平局从输出上看不出来（拆哪一对，输出都是 `2 1 1`），但规则要求选更早生成的。

**“更早生成的赢”在代码里是怎么做到的**：代码里有一个分支写着“当前簇的 birth 更小才替换”，但它永远不成立。因为列表按 birth 从小到大排，循环里后看到的簇 birth 一定更大。真正起作用的是“完全平局时不替换”：留下的是先遇到的那个，也就是 birth 更小的那个。

### 4.5 两种结束

- **簇数到 N**：`while` 的条件不再成立。N = 1 时一次也不进循环（样例 2）。
- **没有能拆的簇**：所有簇都只剩 1 个点，这一轮没有任何候选，`bestIndex` 还是 −1，`break`。N 比点数多时会走到这里。用例 12 是 3 个点、N = 5，输出 `3`、`2 1`、`1 1 1` 三行就结束了。用例 13 只有 1 个点，输出 `1` 一行。

### 5.2 四个结构体

```cpp
struct Point {
    long long x;
    long long y;
};

    long double x;
    long double y;
};
struct Cluster {
    vector<Point> points;
    int birth;
};

    vector<Point> child0;
    vector<Point> child1;

    long long gradDen;

```

| 结构体 | 装什么 | 说明 |
| --- | --- | --- |
| `Point` | 一个点 | 坐标是整数。用 `long long`（约 9.2×10¹⁸）而不是 `int`（约 2.1×10⁹）：后面要算平方、累加、再相乘，中间结果会超过 `int` |
| `Center` | 一个质心 | 质心是平均值，通常是小数。`long double` 是比 `double` 精度更高的浮点数 |
| `Cluster` | 一个簇 | `points` 是这个簇的所有点；`birth` 是生成顺序 |
| `SplitResult` | 一次试拆的结果 | 两个子簇；下降量的分子 `gradNum` 和分母 `gradDen`；`valid` 表示是否成功 |

### 5.3 getSSENumerator：算 n × SSE

```cpp
long long getSSENumerator(const vector<Point>& pts) {
    long long n = pts.size();
    long long sumX = 0;
    long long sumY = 0;
    long long sumSquare = 0;
    for (const Point& p : pts) {
        sumX += p.x;
        sumY += p.y;
        sumSquare += p.x * p.x + p.y * p.y;
    }
    return sumSquare * n
           - sumX * sumX
           - sumY * sumY;
}
```

它返回的不是 SSE，而是 **n × SSE**。Numerator 是“分子”：SSE = 返回值 ÷ n。

公式怎么来的（μx = sumX ÷ n）：

```text
SSE = Σ[(x − μx)² + (y − μy)²]
    = Σ(x² + y²) − n·μx² − n·μy²              把平方展开，再用 Σx = n·μx 化简
    = sumSquare − (sumX² + sumY²) ÷ n
两边乘 n：
n × SSE = sumSquare·n − sumX² − sumY²
```

用样例 1 验证：sumX = 9，sumY = 9，sumSquare = 2 + 8 + 72 = 82。82 × 3 − 81 − 81 = 84。SSE = 84 ÷ 3 = 28，和 2.2 节手算的一样。

**为什么只返回分子**：除以 n 可能得到小数，小数有误差。后面要判断两个下降量是否“正好相等”（平局规则），必须用整数算。坐标是整数，所以 n × SSE 一定是整数。

范围：最多 100 个点，坐标最大 1000。sumSquare 最大 100 × 2×10⁶ = 2×10⁸，再乘 n 是 2×10¹⁰，`int` 装不下，`long long` 装得下。

### 5.4 splitCluster：试拆一个簇

**准备**

```cpp
SplitResult splitCluster(const vector<Point>& pts) {
    SplitResult result;
    result.valid = false;
    int n = pts.size();
    if (n < 2) {
        return result;
    }
    int minIndex = 0;
    int maxIndex = 0;
    for (int i = 1; i < n; i++) {
        if (pts[i].x < pts[minIndex].x) {
            minIndex = i;
        }
        if (pts[i].x > pts[maxIndex].x) {
            maxIndex = i;
        }
    }
    Center c0 = {
        (long double)pts[minIndex].x,
        (long double)pts[minIndex].y
    };
    Center c1 = {
        (long double)pts[maxIndex].x,
        (long double)pts[maxIndex].y
    };
    vector<int> belong(n, -1);
    vector<int> newBelong(n);
```

- `result.valid = false`：先标成失败，走到函数最后才改成 true。
- `if (n < 2)`：少于 2 个点拆不了。实际走不到，`main` 调用之前已经跳过了单点簇。
- `minIndex`、`maxIndex`：x 最小、x 最大的点的**下标**。循环从 1 开始，下标 0 是初始值。
- `c0`、`c1`：两个初始质心。`(long double)` 把整数坐标转成浮点数；花括号按成员顺序赋值，先 x 后 y。
- `belong(n, -1)`：n 个 −1，表示上一轮“还没分过”。`newBelong` 记这一轮的归属。

**循环体**（`while (true)`，靠最后的 `break` 跳出），分四段：

```cpp
        for (int i = 0; i < n; i++) {
            long double dx0 = pts[i].x - c0.x;
            long double dy0 = pts[i].y - c0.y;
            long double dx1 = pts[i].x - c1.x;
            long double dy1 = pts[i].y - c1.y;
            long double d0 = dx0 * dx0 + dy0 * dy0;
            long double d1 = dx1 * dx1 + dy1 * dy1;
            if (d0 <= d1) {
                newBelong[i] = 0;
            } else {
                newBelong[i] = 1;
            }
        }
```

① 分配。`d0`、`d1` 是距离的平方，只比较远近，不用开根号。`<=` 里的等号让一样远的点归 0 号。

```cpp
        bool same = true;
        for (int i = 0; i < n; i++) {
            if (belong[i] != newBelong[i]) {
                same = false;
                break;
            }
        }
```

② 和上一轮比。有一个点的归属不同，`same` 就是 false。第一轮 `belong` 全是 −1，`same` 一定是 false。

```cpp
        if (cnt0 == 0 || cnt1 == 0) {
            return result;
        }
        Center newC0 = {
            sumX0 / cnt0,
            sumY0 / cnt0
        };
```

③ 新质心。前面先按 `newBelong[i]` 累加两个簇的坐标和（`sumX0` 等）和点数（`cnt0`、`cnt1`），再相除。`sumX0` 是浮点数，除以整数得到浮点数。空簇的检查走不到（3.6 节）。

```cpp
        long double maxMove = max(move0, move1);
        belong = newBelong;
        c0 = newC0;
        c1 = newC1;
        if (same || maxMove < 1e-6L) {
            break;
        }
```

④ 停不停。`move0`、`move1` 是新旧质心之间的直线距离（这里用了 `sqrt`，因为要和 1e-6 这个距离比）。`belong = newBelong` 是整个数组复制，把“这一轮”变成“上一轮”。`1e-6L` 末尾的 `L` 表示 `long double` 常数。

**结尾**

```cpp
    for (int i = 0; i < n; i++) {
        if (belong[i] == 0) {
            result.child0.push_back(pts[i]);
        } else {
            result.child1.push_back(pts[i]);
        }
    }
```

按最后一轮的归属，把点分别放进 `child0` 和 `child1`。

### 5.5 下降量通分成一个分数

```cpp
    result.gradNum =
          parentNum * n0 * n1
        - child0Num * parentN * n1
        - child1Num * parentN * n0;
    result.gradDen =
        parentN * n0 * n1;
```

`parentNum`、`child0Num`、`child1Num` 是父簇和两个子簇的 n × SSE；`parentN`、`n0`、`n1` 是它们的点数。

```text
下降量 = parentNum/parentN − child0Num/n0 − child1Num/n1
三个分母不同，通分到 parentN × n0 × n1：
分子 gradNum = parentNum×n0×n1 − child0Num×parentN×n1 − child1Num×parentN×n0
分母 gradDen = parentN × n0 × n1
```

用样例 1 验证：父簇 84 / 3，子簇 2 / 2 和 0 / 1。gradNum = 84×2×1 − 2×3×1 − 0×3×2 = 162，gradDen = 3×2×1 = 6。162 ÷ 6 = 27，和 2.3 节一致。

下降量从头到尾是“分子、分母”两个整数，没有做过除法。

### 5.6 compareGrad：比较两个分数

```cpp
int compareGrad(long long numA, long long denA,
                long long numB, long long denB) {
    __int128 left =
        (__int128)numA * denB;
    __int128 right =
        (__int128)numB * denA;
    if (left > right) {
        return 1;
    }
    if (left < right) {
        return -1;
    }
    return 0;
}
```

分数比大小不做除法，而是交叉相乘：numA/denA > numB/denB 等价于 numA × denB > numB × denA。两个分母都是正数，这样变形才成立。

例：4.2 节第 2 轮，当前簇 DEF 的下降量是 45 / 6（= 7.5），目前最好的 ABC 是 180 / 6（= 30）。left = 45 × 6 = 270，right = 180 × 6 = 1080。left < right，返回 −1：DEF 更小，不换。

因为全是整数运算，“相等”（返回 0）是可靠的，平局规则就建立在它上面。

**`__int128` 是什么**：GCC 提供的 128 位整数，范围约 ±1.7×10³⁸。`(__int128)numA * denB` 先把 `numA` 转成 128 位再乘，乘法在 128 位里进行，不会溢出。它不是标准 C++，g++ 和这道题的判题机支持，换编译器可能不行。

<details>
<summary>进阶：这道题里 long long 其实够用</summary>

按题目范围估算乘积 numA × denB 的上限：

- numA = 下降量 × denA，下降量不超过父簇的 SSE。
- 父簇的 SSE 不超过 nA × 500000：每个点到 (500, 500) 的距离平方最多是 500² + 500² = 500000，而质心是让距离平方和最小的位置。
- denA = nA × n0 × n1，不超过 nA³ ÷ 4。

所以 numA 不超过 500000 × nA⁴ ÷ 4，nA = 100 时是 1.25×10¹³。denB 不超过 100³ ÷ 4 = 2.5×10⁵。乘积不超过约 3.1×10¹⁸，小于 `long long` 的上限 9.2×10¹⁸。

用 `__int128` 是省去这番估算的保险写法。

</details>

### 5.8 main

**读入和第 0 轮**

```cpp
    vector<Cluster> clusters;
    clusters.push_back({
        allPoints,
        0
    });
    int birthCounter = 1;
    printClusterSizes(clusters);
```

`clusters` 是簇列表。先放进初始簇：全部点，birth = 0。花括号按 `Cluster` 的成员顺序赋值。`birthCounter` 是下一个新簇的编号。还没拆，先输出一行。

**选簇**

```cpp
    while ((int)clusters.size() < N) {
        int bestIndex = -1;
        SplitResult bestSplit;
        for (int i = 0; i < (int)clusters.size(); i++) {
            if (clusters[i].points.size() < 2) {
                continue;
            }
            SplitResult cur =
                splitCluster(clusters[i].points);
            if (!cur.valid) {
                continue;
            }
            if (bestIndex == -1) {
                bestIndex = i;
                bestSplit = cur;
                continue;
            }
```

- `bestIndex`：目前最好的候选是列表里的第几个，−1 表示还没有。`bestSplit` 是它的试拆结果。
- 点数小于 2 的簇 `continue` 跳过。
- `!cur.valid` 的三行走不到：`splitCluster` 不会失败。
- `bestIndex == -1`：这是第一个候选，没有比较对象，直接记下来。

```cpp
            if (cmp > 0) {
                bestIndex = i;
                bestSplit = cur;
            }
            else if (cmp == 0) {
                if (curSize > bestSize) {
                    bestIndex = i;
                    bestSplit = cur;
                }
                else if (curSize == bestSize &&
                         clusters[i].birth <
                         clusters[bestIndex].birth) {
                    bestIndex = i;
                    bestSplit = cur;
                }
            }
```

`cmp` 是 `compareGrad(当前簇, 目前最好的)` 的结果。

| 情况 | 动作 |
| --- | --- |
| `cmp > 0`：当前簇的下降量更大 | 换成当前簇 |
| `cmp == 0`，当前簇的点更多 | 换成当前簇 |
| `cmp == 0`，点数相同，当前簇的 birth 更小 | 换成当前簇。**这个分支走不到**（4.4 节） |
| 其余（`cmp < 0`；或平局但当前簇点更少；或完全平局） | 什么都不做 |

**真拆和输出**

```cpp
        if (bestIndex == -1) {
            break;
        }
        clusters.erase(
            clusters.begin() + bestIndex
        );
        clusters.push_back({
            bestSplit.child0,
            birthCounter++
        });
        clusters.push_back({
            bestSplit.child1,
            birthCounter++
        });
        printClusterSizes(clusters);
```

- `bestIndex == -1`：没有任何簇能拆，提前结束。
- `clusters.begin() + bestIndex` 是第 bestIndex 个元素的位置；`erase` 删掉它，后面的元素依次前移。
- `birthCounter++`：先用现在的值当 birth，再把 `birthCounter` 加 1。

| --- | --- | --- |
| `splitCluster` | `if (n < 2) { return result; }` | `main` 调用前已经跳过了单点簇 |
| `splitCluster` | `if (cnt0 == 0 \|\| cnt1 == 0) { return result; }` | 两个簇都不会是空的（3.6 节） |
| `main` | `if (!cur.valid) { continue; }` | 上面两处都不发生，`valid` 一定是 true |
| `main` | `else if (curSize == bestSize && clusters[i].birth < clusters[bestIndex].birth)` | 列表按 birth 从小到大排，后看到的簇 birth 更大（4.4 节） |

它们都是保险，留着不影响结果。我用覆盖率工具（gcov）在原始代码上核对过：14 个用例跑完，只剩这四处没执行；再加 3000 组随机数据，这四处仍然一次都没有执行。

## 8. 复杂度和数据范围

- 一轮里每个簇都试拆一次。一次 K-means 的一轮循环要看簇里的每个点，一轮 Bi-K-means 的所有簇加起来是 L 个点。所以一轮 Bi-K-means 的时间是 O(L × K-means 的循环轮数)。
- 最多 N − 1 轮，N 最多 20，L 最多 100，K-means 一般几轮就停。总计算量很小，用例 14（N = 20，L = 100）本机约 0.06 秒，远低于 1 秒的限制。
- 每一轮都把所有簇重新试拆一遍，上一轮算过的也不保存。数据这么小，这样写最简单，没有必要优化。
- 空间：点和簇列表，O(L)。

## 9. 易错点

- 忘了输出第 0 轮（还没拆时的那一行）。
- 选簇时以为“点多的先拆”。第一级规则是下降量最大（用例 08）。
- 平局规则的顺序弄反：先比点数，再比生成先后（用例 09、11）。
- 初始质心随机选，或者选成别的点。必须是 x 最小和 x 最大的点。
- 一样远的点归哪个簇。这份代码归 0 号（`<=`）。
- 用浮点数比较两个下降量是否相等。浮点数有误差，可能把平局判成不平局。代码用整数分子、分母加交叉相乘。
- 坐标用 `int`：中间的平方和、乘积会溢出。
- N 比点数多时死循环或越界。代码用“没有候选就 `break`”处理。
- 输出每行末尾多一个空格，或者没有按从大到小排。
